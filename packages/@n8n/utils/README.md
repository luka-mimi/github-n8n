## 功能

- **可重用逻辑**：使用模块化可组合函数构建复杂的、有状态的功能，轻松实现重用。
- **一致的模式**：在 n8n 包中享受统一的方法，使集成和维护变得轻而易举。
- **类型安全且可靠**：受益于 TypeScript 支持，提高开发者体验和代码的健壮性。
- **通用功能**：设计为在前端和后端无缝工作。
- **易于测试**：模块化设计简化了测试、维护和快速开发。
